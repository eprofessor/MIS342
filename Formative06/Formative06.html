Assignment Overview — LuckyTire

LuckyTire employees perform different tasks: scanning many records, reviewing one record in detail, and editing a selected record. Access provides different form designs for those different workflows.

This is a formative assignment. The goal is to learn by building, testing, and checking the database work. You do not need to submit screenshots, a PDF, or Digital Artifact Notebook evidence.

Exercise 1 — Match the Form Design to the LuckyTire Task
  1. Download LuckyTire_Normalized_Formative06.accdb. Save a working copy as Formative06_LuckyTire.accdb.
  2. Choose a useful LuckyTire table or query and create a Multiple Items form. Save it as frmMultipleItems.
  3. Create a Split Form using an appropriate customer, tire, or sales record source. Save it as frmSplitView.
  4. For one form, improve the layout by changing labels, widths, tab order, title, or other visible properties so that the main business fields are easy to find.
  5. If the data supports it, add one visual or validation aid such as conditional formatting, a combo box, or a locked calculated control.
  6. Navigate through several records in each form and verify which form is better for scanning many records and which is better for editing one selected record.
  7. Make one harmless test edit in your working copy, confirm that the underlying table changes as expected, and then restore the original value.
  8. Use Hermes to propose three form test cases: one normal case, one unusual/boundary case, and one potential user-error case.
  9. Perform the three tests in Access and record mentally which test revealed the most useful information.
  10. Save and close the database.
