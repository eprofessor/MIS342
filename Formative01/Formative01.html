Assignment Overview — LuckyTire

LuckyTire is a growing tire retailer and automotive service business. Employees need to record service visits, find information about past work, enter new records efficiently, and communicate useful information to managers.

LuckyTire has a small service-order data file. In this assignment you will move that data into Microsoft Access and create the basic objects of a database application. Later MIS342 assignments will expand the LuckyTire database and connect Access to external database systems.

This is a formative assignment. The goal is to learn by building and checking the objects. You do not need to submit the Access file, screenshots, a PDF, or Digital Artifact Notebook evidence.

Exercise 1 — Build and Compare the Core Access Objects
  1. Download LuckyTire_ServiceOrders.csv to your local Formative01 working folder.
  2. Open Microsoft Access and create a blank database named Formative01_LuckyTire.accdb.
  3. Import LuckyTire_ServiceOrders.csv as a new table named ServiceOrders. Confirm that the first row contains field names.
  4. During the import, choose ServiceOrderID as the primary key. After the import, verify that the table contains 12 records.
  5. Open the table in Datasheet View. Identify one field, one record, and the primary key.
  6. Use the Simple Query Wizard to create a query named qryServiceOrders containing ServiceOrderID, CustomerName, ServiceDate, ServiceType, and AmountPaid. Open the query and verify that it returns 12 records.
  7. Use the Form tool to create a form based on the ServiceOrders table. Save it as frmServiceOrders. Move through several records and verify that the form displays one service order at a time.
  8. Use the Report tool to create a report based on qryServiceOrders. Save it as rptServiceOrders. Verify that the report displays the service-order information in a format intended for viewing or printing.
  9. Close each object and confirm that the Navigation Pane now contains the ServiceOrders table, qryServiceOrders query, frmServiceOrders form, and rptServiceOrders report.
  10. Save and close Formative01_LuckyTire.accdb.
