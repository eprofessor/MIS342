Assignment Purpose and Learning Outcomes

Formative07 focused on turning records into management information. Summative07 asks you to create multiple LuckyTire report outputs for different audiences and verify their grouping, sorting, and calculations.

After completing this assignment, you will be able to:

  1. Modify and format an existing report for readability.
  2. Group and summarize numeric information in a report.
  3. Create a multi-table query as a reliable report source.
  4. Create a custom management report and verify totals.
  5. Create an audience-specific output such as mailing labels.

Primary course learning-outcome alignment: CLO 6, with supporting evidence for CLOs 4, 8, and 11.

Questions 1 through 6 require concise answers of no more than 500 characters. The Final Assignment Reflection allows a longer response.

Exercise 1 — Refine the Tire Report
  1. Download LuckyTire_Normalized_Summative07.accdb and save a working copy as Summative07_LuckyTire.accdb.
  2. Open the existing tire report (such as rptTiresReport) or create an equivalent report if needed.
  3. Group the report by Manufacturer and display the average UnitPrice for each manufacturer.
  4. Apply conditional formatting to UnitPrice for a meaningful threshold present in the data.
  5. Adjust labels/column widths so the report is readable and save the report.
  6. Verify one manufacturer's average using the underlying tire records.

Exercise 2 — Custom Tire-Type Report
  1. Create a multi-table query using customer, sales, and tire data. Include customer name, Quantity, TireType, Manufacturer, ModelName, and UnitPrice; save it as qryTireType.
  2. Sort the query by TireType, Manufacturer, and customer Last name.
  3. Create a report based on qryTireType and save it as rptTireType.
  4. Group first by TireType and then Manufacturer.
  5. Show total Quantity at the appropriate group levels and add a clear title/date/page number.
  6. Verify one quantity total against qryTireType.

Exercise 3 — Customer Mailing Output
  1. Use the customer table as the source for a mailing-label report or equivalent customer-address output.
  2. Place customer name and address fields in a readable postal format.
  3. Sort by Zip and then Last name.
  4. Save the report as rptCustomerMailingLabels.
  5. Preview multiple labels and verify at least two addresses against the customer table.
  6. Optionally ask Hermes to identify one audience/readability or verification issue, then check it in Access.
