Assignment Overview — LuckyTire

LuckyTire managers need more than simple selection queries. You will use several Access query tools to answer questions involving user-supplied criteria, duplicate activity, missing related records, and summarized data.

This is a formative assignment. The goal is to learn by building, testing, and checking the database work. You do not need to submit screenshots, a PDF, or Digital Artifact Notebook evidence.

Exercise 1 — Use Advanced Queries to Investigate LuckyTire Data
  1. Download LuckyTire_Normalized_Formative05.accdb. Save a working copy as Formative05_LuckyTire.accdb.
  2. Create a parameter query that asks for a city, manufacturer, tire type, or another meaningful value that exists in the database. Save it as qryParameter and test at least two parameter values.
  3. Use the Find Duplicates Query Wizard on a table/field where duplicate business activity is meaningful. If the selected field contains no duplicates, explain that result and try a second reasonable field.
  4. Use the Find Unmatched Query Wizard to identify records in one table without related records in another where the relationship supports the question, such as customers without sales.
  5. Create a crosstab or totals query that summarizes sales quantity or another numeric measure by two useful business dimensions. Save it as qryLuckyTireCrosstab or qryLuckyTireTotals.
  6. Open SQL View for at least one query and read the SQL that Access generated.
  7. Use Hermes to explain that query's logic or propose an alternative Access SQL solution. Clearly tell Hermes that the target dialect is Microsoft Access SQL.
  8. Run the Access/Wizard solution and any alternative you test. Compare the returned records or totals.
  9. Review one relevant field property such as Required, Validation Rule, input mask, or indexed setting and explain how it can prevent or detect bad data.
  10. Save and close the database.
