Assignment Purpose and Learning Outcomes

Formative01 introduced the basic jobs of tables, queries, forms, and reports. Summative01 asks you to build those objects more independently for LuckyTire, verify that they behave correctly, and explain why each object is useful.

After completing this assignment, you will be able to:

  1. Configure an Access table using appropriate fields, data types, records, and a primary key.
  2. Create, run, and verify a query that answers a LuckyTire business question.
  3. Create and test a form that changes the underlying data correctly.
  4. Create a report that communicates selected LuckyTire information clearly.
  5. Back up and maintain an Access database using appropriate file-management practices.
  6. Explain how the main Access objects work together as a simple business database application.

Primary course learning-outcome alignment: CLO 2, with introductory Apply-level evidence supporting CLOs 3, 4, 5, 6, and 8.

Questions 1 through 6 require concise answers of no more than 500 characters. The Final Assignment Reflection allows a longer response.

Exercise 1 — Table Structure and Data Integrity
  1. Download LuckyTire_ServiceOrders.csv.
  2. Create a blank Access database named Summative01_LuckyTire.accdb.
  3. Import the CSV as a table named ServiceOrders and confirm that the first row contains field names.
  4. Set ServiceOrderID as the primary key.
  5. In Design View, verify that ServiceDate uses Date/Time, TireQuantity uses a numeric data type, and AmountPaid uses Currency. Correct a data type if necessary.
  6. Open Datasheet View and verify that the table contains 12 records before you add any new record in Exercise 2.

Exercise 2 — Query and Form
  1. Create a query in Design View using ServiceOrders.
  2. Include ServiceOrderID, CustomerName, ServiceDate, ServiceType, TireBrand, TireQuantity, and AmountPaid.
  3. Set the AmountPaid criterion to >=900 and sort AmountPaid in descending order.
  4. Save the query as qryHighValueServiceOrders and run it. With the original 12 starter records, verify that the query returns 4 records.
  5. Create a form based on ServiceOrders and save it as frmServiceOrders.
  6. Use the form to add one fictional LuckyTire service record with a unique ServiceOrderID and an AmountPaid value below $900.
  7. Reopen qryHighValueServiceOrders and verify that the new low-value record does not appear and that the query still returns 4 records.
  8. Open the ServiceOrders table and verify that the new form-entered record is stored in the table.

Exercise 3 — Report and Database Maintenance
  1. Create a report based on qryHighValueServiceOrders.
  2. Include the major fields needed to identify the service order and amount. Use a clear title such as LuckyTire High-Value Service Orders.
  3. Sort the report by AmountPaid in descending order if the report does not inherit the desired order.
  4. Save the report as rptHighValueServiceOrders.
  5. Open the report in Print Preview and verify that it shows the same four high-value service orders as the query.
  6. Create a backup copy of the database using an instructor-approved Access/Windows backup method and give the backup a clear filename containing Summative01 and Backup.
  7. Run Compact and Repair Database on your working database.
  8. Reopen the database and confirm that ServiceOrders, qryHighValueServiceOrders, frmServiceOrders, and rptHighValueServiceOrders still open correctly.
