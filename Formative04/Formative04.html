Learning Objectives

This assignment prepares you for Summative04 and continues the LuckyTire database application case.

After completing this assignment, you will be able to:

  1. Create and use a form for business data entry and navigation.
  2. Create a main form/subform that represents a one-to-many relationship.
  3. Create a report that groups and summarizes related business data.
  4. Use Hermes to review a design choice and independently verify the recommendation in Access.

Assignment Overview — LuckyTire

LuckyTire employees should not need to work directly in raw tables for every task. You will create user-facing Access objects that make customer/sales information easier to enter, navigate, and communicate.

This is a formative assignment. The goal is to learn by building, testing, and checking the database work. You do not need to submit screenshots, a PDF, or Digital Artifact Notebook evidence.

Exercise 1 — Build a LuckyTire User Interface and Management Output
  1. Download LuckyTire_Normalized_Formative04.accdb. Save a working copy as Formative04_LuckyTire.accdb.
  2. Use the Form Wizard to create a customer form containing the major customer fields. Save it as frmCustomer.
  3. Use the form to find at least two different customers and verify that the form displays the same values as the underlying table.
  4. Create a main form and subform that displays one customer in the main form and that customer's related sales in the subform. Save the main form as frmCustomerSales.
  5. Move among several customers and verify that the subform changes to show only related sales.
  6. Create a report using tire/sales information. Group the report by a meaningful field such as manufacturer or tire type and include a quantity or sales-related summary when the starter data supports it. Save it as rptLuckyTireSales.
  7. Open the report in Report View or Print Preview and verify that grouping and totals are based on the intended records.
  8. Use the Hermes checkpoint from this page: describe your main-form/subform relationship and report purpose, then ask Hermes to identify one usability or verification check.
  9. Perform the suggested check in Access. Accept, revise, or reject the suggestion based on what you observe.
  10. Save and close the database.
