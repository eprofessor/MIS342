Assignment Purpose and Learning Outcomes

Formative05 introduced advanced Access queries and validation. Summative05 requires you to choose appropriate query types and controls for LuckyTire business questions and prove that generated results are correct.

After completing this assignment, you will be able to:

  1. Configure an appropriate validation or input rule.
  2. Create and test a parameter query.
  3. Use duplicate or unmatched query logic for a data-quality/business question.
  4. Create a totals or crosstab query for management analysis.
  5. Inspect Access SQL and verify generated-query results.

Primary course learning-outcome alignment: CLOs 4 and 8, with supporting evidence for CLO 11.

Questions 1 through 6 require concise answers of no more than 500 characters. The Final Assignment Reflection allows a longer response.

Exercise 1 — Data Validation
  1. Download LuckyTire_Normalized_Summative05.accdb and save a working copy as Summative05_LuckyTire.accdb.
  2. Choose one field where invalid values could harm LuckyTire data quality, such as Quantity, UnitPrice, Year, State, Phone, or another appropriate field in the starter.
  3. Create an appropriate Validation Rule, Required setting, input mask, or indexed/no-duplicates rule.
  4. Enter a harmless invalid test value in the working copy and confirm that Access prevents or flags it.
  5. Restore the valid value and verify that normal entry still works.

Exercise 2 — Parameter and Exception Query
  1. Create a parameter query that asks for a meaningful LuckyTire value such as City, Manufacturer, TireType, or another field present in the starter. Save it as qryLuckyTireParameter.
  2. Run it with at least two valid parameter values and one value that returns no rows.
  3. Use Find Unmatched or Find Duplicates Query Wizard where the data support a meaningful question, such as customers without sales or repeated business activity.
  4. Save the second query as qryLuckyTireException.
  5. Verify at least one returned or absent record against the source tables.

Exercise 3 — Totals or Crosstab Analysis
  1. Create a totals or crosstab query that summarizes a numeric measure such as Quantity or sales amount by one or two meaningful business dimensions.
  2. Save it as qryLuckyTireSummary.
  3. Run the query and verify one displayed total by checking the underlying records.
  4. Open SQL View and identify the aggregate/grouping logic; for a crosstab, identify the Access TRANSFORM/PIVOT structure.
  5. Optionally ask Hermes to explain the SQL, then confirm the explanation by returning to Design View and the source data.
